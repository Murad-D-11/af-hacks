## Team

TradePass was built in 24 hours at **AF Hacks: Growing Canada** (Ascendance Foundry × Waterloo Venture Group, September 2026), where it placed in the top 10. We split the work in half:

- **Murad ([Murad-D-11](https://github.com/Murad-D-11)):** the employer verification side. ElevenLabs agent setup, the employer verification link and form, the recorded webcam interview, and the evidence package and PDFs.
- **Abdullah Bakuvi ([A-bakuvi](https://github.com/A-bakuvi)):** the app foundation and the worker side. Project scaffolding, data model and store, seed data and API routes, the worker voice intake and claim parsing, the worker dashboard (verified hours, 309A skill-set coverage, blockers) and sending verification requests.

Built with AI-assisted development (Claude Code). The app itself lives in [`tradepass/`](tradepass/); see its README for setup and the demo script.
